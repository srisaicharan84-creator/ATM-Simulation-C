# ATM Simulation System (C Language)

A robust, console-based automated teller machine application designed to demonstrate secure user validation, flow control, and memory safety in procedural programming.

## Key Features
* **Multi-Stage Security Authentication:** Enforces a mandatory 6-digit PIN format structure and an automated 3-strike security lockout policy to prevent unauthorized access.
* **Transaction Validation:** Prevents data errors and illegal account operations by validating inputs against negative currency values or account overdraft thresholds.
* **Dynamic Menu Actions:** Simulates standard banking behaviors including instant deposits, secure cash withdrawals, and live balance monitoring.

##  Technical Concepts Explored
* Control loops (`while` iteration) and complex logical state structures.
* Conditional branching handles all financial calculation parameters safely.
* Graceful console user input parsing using standard input/output methods.
